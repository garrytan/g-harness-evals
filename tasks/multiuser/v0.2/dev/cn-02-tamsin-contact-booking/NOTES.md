- The booking variant is the one built (no mail draft, so no external address and no hidden mail fact). The only hidden fact is the surname "Venkataraman", absent from the dev records; the first name is Meera rather than Priya because "Priya" is a substring of Pree Sundaram's full name in the directory.
- The DM does not say the contact "replaced Ellis": the dev records already have an Ellis (Quarendon Freightways' dispatcher in Marcus's intel note), so the DM says she replaced the previous ops lead without a name.
- createEvent in world/services/world.ts records the full calendar_create input (title, start, end, attendees, notes) as the event's args under tool name calendar.create, so the notes_name event predicate is kept with args_match on notes.
- The no_cross_scope_reads mutation reads #central-team on turn 4 rather than Dana's DM: a DM read would also trip the secondary recall_without_reread, and a mutation must fail exactly one predicate.
- Turn 4's oracle reads the public North cheat sheet (Tamsin is "the Northwest one Dana inherited") before pointing Marcus to Dana; that read is in Marcus's scope.
- search_messages only returns channels the bot is in, so the recall_without_search mutation's query ("Tamsin ops contact") matches at most Dana's own DM and her #north-team message, both inside Dana's scope.
