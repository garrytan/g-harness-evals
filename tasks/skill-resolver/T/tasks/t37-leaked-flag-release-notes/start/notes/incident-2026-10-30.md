# Incident: internal flag name in the 4.12 release notes

- 2026-10-30, the 4.12 notes went out with the line "Faster sync for large workspaces (exp_delta_sync_v2 is now on for everyone)".
- exp_delta_sync_v2 is an internal feature flag. Two customers asked in support how to "turn on exp_ flags" for other features; one competitor's blog quoted it.
- The agent drafting the notes copied the PR title, which carried the flag name. scripts/check.sh passed: it only looks for PR numbers, TODO/FIXME/WIP and the three headings.
- Mira approved it in a hurry and did not catch it.
- All our flags start with exp_ (see config/flags.yaml). Customers should only ever see the feature described.
