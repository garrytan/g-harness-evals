# Fernleaf brand notes (retyped from the agency PDF)

- Feel: calm, botanical, a bit old-fashioned, like a tea shop with good stationery.
- Main green #2F5D50 for headings and the logo. Secondary sage #8FA998. Accent terracotta #C2603F for buttons and links. Background warm paper #F6F1E7. Body text near-black #1F2421.
- Fonts: headings in Fraunces (serif), weight 600. Body in Inter, 16px, line height 1.6.
- Corners: slightly rounded, 6px on buttons and cards, never pill shapes.
- Spacing on an 8px grid.
- Buttons: terracotta background with white text; on hover they turn main green.
- No drop shadows. Use thin 1px sage borders instead.
- Never put the green and the terracotta next to each other in large blocks.
