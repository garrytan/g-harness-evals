## Variant: Split summary

### Design stance
Choices on the left, a sticky order summary on the right, like a settings page.

### Key choices
- Layout: two columns; summary panel 340 px.
- Typography: system sans, one size step for the price.
- Color: white and light grey with one blue accent for the action.
- Interaction: option buttons toggle; the summary follows the frequency choice.

### Trade-offs
- Strong at: changing grind, frequency or card without leaving the page.
- Weak at: busier than a receipt; poor on narrow phones without a rework.

### Best for
- New subscribers setting up their first order.
