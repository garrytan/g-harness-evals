## Variant: One-tap sheet

### Design stance
Checkout is a bottom sheet with everything pre-filled; changing anything is hidden behind one link.

### Key choices
- Layout: bottom sheet over a dark backdrop.
- Typography: system sans, large price.
- Color: espresso brown with a terracotta pay button.
- Interaction: "Change" opens the options; pay confirms inline.

### Trade-offs
- Strong at: speed; one tap for the common case.
- Weak at: hides options, which may surprise first-time buyers.

### Best for
- Mobile visitors coming back from a reminder email.
