# Fix acme/tiler#125: wrong Content-Type for .pbf tiles

Issue: https://github.com/acme/tiler/issues/125

## Context

Vector tiles are served as text/plain instead of application/x-protobuf, and MapLibre refuses to decode them behind the CDN, which sniffs the type. The mapping lives in server/handlers.go contentTypeFor().

## Steps

1. Clone acme/tiler and create a branch from main: `git checkout -b 125-pbf-content-type origin/main`.
2. In contentTypeFor(), return application/x-protobuf for .pbf (and .mvt).
3. Add a handler test for the .pbf Content-Type and keep .png unchanged.
4. Run `go test ./server/...`.
5. Commit, push and open a PR against main.

## Acceptance criteria

- .pbf responses carry Content-Type: application/x-protobuf.
- Other tile types are unchanged.
