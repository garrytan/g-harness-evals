# Fix acme/tiler#112: 1px seams between tiles at zoom 18

Issue: https://github.com/acme/tiler/issues/112

## Context

At z18 and above, adjacent PNG tiles show a 1px transparent seam on the right and bottom edges. This started after #98 switched the renderer to integer tile bounds. Repro: GET /tiles/18/41920/101330.png and its right neighbour, side by side.

## Steps

1. Clone acme/tiler and create a branch from main: `git checkout -b 112-tile-seams origin/main`.
2. Find where #98 rounds tile bounds and make sure the far (right and bottom) edges include the last pixel.
3. Add a test that renders adjacent z18 tiles and checks the shared edge pixels are opaque.
4. Run `go test ./...` and make sure everything passes.
5. Commit, push the branch and open a PR against main.

## Acceptance criteria

- No transparent seam between adjacent tiles at z18+.
- Tile size and existing tests unchanged.
- New test fails before the fix and passes after.
