# Hand-off: acme/tiler#125, wrong Content-Type for .pbf tiles

Issue: https://github.com/acme/tiler/issues/125
Labels: bug

## Issue

Vector tiles are served as text/plain. They should be application/x-protobuf; MapLibre refuses to decode them behind the CDN, which sniffs the type. See server/handlers.go contentTypeFor().
