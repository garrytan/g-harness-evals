# Lobby screen brief: Marlow Library

- Where: the 55 inch TV in the lobby, 1920x1080, Chrome in kiosk mode on a small mini PC, 8:00 to 20:00 every day.
- Feel: calm, like light moving through water. Slow drift, nothing flashy.
- Colors: deep teal background, amber and pale gold points, one soft coral accent.
- Motion: points drifting along a smooth flow, leaving soft fading trails. About once a minute the whole piece gets slightly brighter, then dimmer again, like a slow breath.
- Must not: flash, show any text, or need a mouse or keyboard.
- The library liked one test version and wants that same look every morning.
