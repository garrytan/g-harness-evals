# Contributing

Before submitting a change:

- Run the repository test suite and ensure all tests pass, including tests in `tests_feature`.
- Run `ruff check .` using the repository's `ruff.toml`; it must report no errors.
- Add a bullet under `## Unreleased` in `CHANGELOG.md` for every change.
- Make no unrelated changes.
- Keep all commits on the feature branch. Never push to main.
