# Metering proxy, budget ledger and price table

Vendored from [gbrain-evals](https://github.com/garrytan/gbrain-evals) v0.10.128 (`6999ebc9`) and [gbrain](https://github.com/garrytan/gbrain) (`src/core/model-pricing.ts`, `embedding-pricing.ts`, `model-id.ts`), both MIT. Changes: import paths, and `sanitize.ts` reduced to the leak tripwire the proxy uses.

- `proxy/metering-proxy.ts`: the only network exit for a harness container's model calls. In lease mode it strips inbound credentials and injects the real key from its own environment, allows only listed provider routes and priced models, bounds input tokens by request bytes, injects or enforces an output-token cap, reserves the worst case in the ledger before forwarding (concurrent requests serialize on the ledger), meters streamed responses from their usage events, refuses bodies carrying a forbidden marker, and appends one usage line per request (never a body or a key). Per-trial attribution: the runner binds a slot (the path segment the container's base URL carries) to a trial key with `POST /__proxy/bind`, and reads the meter with `/__proxy/finalize`; with `--control-token` a container cannot move charges. See the header comment for the CLI.
- `ledger/budget-ledger.ts`: SQLite ledger (WAL, synchronous=FULL). Reserve before dispatch, settle to provider usage, cap recorded in the ledger with who set it and why, refusals name the fix. `docs/budget-ledger.md` in gbrain-evals describes the operator commands; the same CLI works here as `bun runner/ledger/budget-ledger.ts`. The program ledger for this evaluation lives outside the repository (the project drive, `harness-eval/ledger/program-ledger.sqlite`); its recorded cap is $2,000 (plan D10, set 2026-10-22), and every paid run opens its lease in it.
- `contracts.ts`: the shapes the runner, the adapters (`TurnRequest`, `TurnResponse`), the graders (`TrialEvidence`, `GradeResult`) and the scripted oracle and mutation solutions (`Script`) agree on. See docs/tasks.md and docs/adapters.md.
- `pricing/`: the list-price table (`canonicalLookup`). A model with no row cannot be reserved and so cannot run (HE-PIN-002). Register a price before a cell runs, in the same commit as the preregistration amendment that adds the model.
