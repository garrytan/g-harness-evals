# gbrain results measured on older builds

**Some of our published gbrain numbers were measured on gbrain builds that are now weeks old, and we are not running them again.** Each result below stays published, labelled with the gbrain build it was measured on.

- **Why they stay.** gbrain ships several releases a day. Since 2026-11-16 we re-run a gbrain number from an older build only when a named gbrain change since that build could plausibly move it. Otherwise the number stays published, labelled with its build, until a monthly refresh on that month's stable gbrain release.
- **Why these are not re-run.** Most of them ran on Claude Haiku 5.5 or Sonnet 5.5, which are no longer models we test. The rest tested something other than gbrain itself, or asked a question that a later run asked again on a newer build.
- **Nothing changes in the reports.** Every number below is as its run report published it, and each run folder records its build in full, in its preregistration, its report or its results manifests. This page adds the label, the reason and a pointer to the newest measurement.

**How to read a line.** "Measured on" gives the gbrain release, the first 8 characters of its commit, and the UTC dates of the run's counted tries. "The newest measurement of this question" is the latest published run that asks the same question, or "none planned".

Other published gbrain results are not on this page because they are being measured again on a newer gbrain or folded into later runs.
