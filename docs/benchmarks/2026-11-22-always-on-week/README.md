# Always-on week: memory across conversations

- **gbrain with live ingestion carried facts across conversations about twice as often as a plain memory folder, for Claude Opus 5.5 in Claude Code: 78% against 39% of memory checks (paired difference +39 points, 95% range +19 to +58).** Use gbrain with live ingestion for always-on Opus 5.5 setups in Claude Code.
- **With no memory, Opus 5.5 passed 0 of 120 checks.** An always-on agent does not carry last week's facts from its session history.
- **QM as shipped passed 3 of 120, because its default Isolated posture keeps channel memory out of DMs.** Its memory capture ran in every trial.
