## Next time

### What we'd change if we ran this again

- Run both cells of a pair on the same machine when wall time matters, because each cell had its own VM, so wall time per turn is confounded with the machine.

### Ideas to improve the eval

- Add a probe where the harness chooses its own sources, including one outside the member's grant, because no harness sent its own source list in 517 calls, so the tap's refusal of an out-of-grant source list went untested in counted trials.
- Confirm told-scoped against told-company at the next held-out set's first opening, because this run retested scoping on the tasks where the company brain run had already found the leaks, so it counts only as development evidence.
