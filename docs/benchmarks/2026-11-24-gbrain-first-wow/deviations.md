## Operations

- **Shards (2026-11-26, before the first counted trial).** The two particle-1 cells (qm-particle-native, qm-particle-plain) run as their own shard, s2b-qm-particle, so they can be held on their own, and qm-sol-plain runs alone as s2. The Particle account returned `402 insufficient_credits` on a one-token call at about 08:13 UTC, so s2b is held until a one-token call returns 200. No cell is split across machines, and every shard runs from commit 6384ca3e. No counted number depends on this.
- **The copy of the results that leaves the controller (2026-11-26, 09:57 UTC, decided by the coordinating agent).** The plan's launch path mirrors each shard's whole results tree, one file per trial file, into a Capy drive folder every 20 minutes. That drive had stopped saving because its file list was too long, and the mirror would have added about 100,000 files. So:
  - The loose mirror is off for every shard. The canary shard (s4-cc) was already running with it, and its mirror stopped at 09:58:49 UTC without its run being touched. The files it had queued were left in place.
  - The other five shards launched without `--replicate-to`.
  - Every hour, each shard's finished trials since the last hour are packed into `tar.zst` archives of at most 100 MiB and written to a drive folder that saves. An archive counts as off the controller only once its sha256 matches the file in a saved drive version. Each hour also writes a small archive with the shard's trials.jsonl, a copy of its ledger, its image record and its logs.
  - Each archive holds every file of its trials, the packed gbrain database (`brain.pglite.tgz`) included. The first pack, at 10:37 UTC, left out each trial's `state/`, `workspace/` and `home/` folders, as the mirror did for `state/` and `workspace/`. A check then showed that the scorer reads the agent's files from `state/` (Claude Code and Codex) and `workspace/` (QM). So at 11:05 UTC that pack was deleted and every trial was packed again in full.
  - **Check that the copy alone can re-score a trial (11:12 UTC).** One finished trial per running shard (qm-opus-native, qm-sol-plain, cc-opus-defaults and cc-opus-pr1, all seed 60) was taken from the archives in saved drive version `vver_01M8BRV7DED5D8A4CPZ904RGHE` only, with no file from the controller, and re-scored with `scripts/gbrain-first-wow/pilot-summary.ts`'s `rescore`. All four scores matched the score in the trial's record and the score from the controller's copy. With `state/` removed, the cc-opus-pr1 trial's re-score no longer matched, so those folders have to be in the archives. The two Codex shards had no finished trial yet; their archives get the same check at their first pack.
  - Each shard's VM record and a VM map are copied to a private drive folder every hour.
  No trial, grade or counted number depends on this. It changes only where the second copy of the results lives.
- **Launch attempts that failed before any trial (2026-11-26).** The first launch of the other five shards at 09:59 UTC staged all five at once, and each staging needed about 10 GB of the controller's disk, so all five stopped at sync with "No space left on device" (exit 3). Each VM was destroyed within two minutes, and none ran a trial. Unused local Docker images and an old export copy were deleted to free space. The shards were then launched one at a time, each after the one before it had finished syncing. s5-codex failed at sync once more at 10:13 UTC for the same reason, with no trial run, and was relaunched alone. No counted number depends on this.
- **The Codex shards' one-trial smoke lease (2026-11-26).** Both Codex shards (s5-codex, s6-codex) then failed their one-trial smoke, which runs before the counted run under its own $3.00 lease. The metering proxy reserves about $2.10 for each GPT-6.2 Sol call at the 128,000-token output cap, so a second call in a smoke trial would have taken the smoke past $3.00, and the proxy refused it with HTTP 402. Every smoke trial ended as `model_error`, and the smokes cost $0.64 (s5-codex) and $0.20 (s6-codex). Both shards were relaunched with `--smoke-lease-usd 12`. The counted leases ($95 and $55) and every counted trial are unchanged. The smoke trials run under their own run id and are not counted.
