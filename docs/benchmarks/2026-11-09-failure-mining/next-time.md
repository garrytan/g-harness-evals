## Next time

### What we'd change if we ran this again

- Report an answer-only reading beside the preregistered gbrain retrieval test, because 108 of the 120 unscoped brain-search failures behind the +9.5 points would have passed without the read-scope check, so the headline counted pages a search returned rather than worse answers.
- When a sensitivity reading counts tries as passes, state whether checks that never decide a grade still count, because that one rule moves the answer-only result without the QM pairs from +2.5 [+0.1, +5.1] to +1.9 [-0.3, +4.5].
