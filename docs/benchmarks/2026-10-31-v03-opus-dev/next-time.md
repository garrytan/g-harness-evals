# Next time: 2026-10-31-v03-opus-dev

The [report](report.md) was published before reports had a Next time section, and a hash pins its text, so the section lives here. Each item comes from the report, its corrections or what we learned running it.

## Next time

### What we'd change if we ran this again

- Give the no-brain cells a lease that covers all their tasks, because the OpenClaw none cell stopped at its lease after 48 of 60 trials and never reached synthesis.
- Check free disk on the controller machine before a six-shard launch, because the first start failed with "No space left on device" while cloning the commit into local scratch.
- Run told-live on Opus beside told-scoped, because the only brain lift any v0.3 run has shown is told-live on corrections, on Haiku, and told-live did not run here.

### Ideas to improve the eval

- Put the needed fact where only memory reaches it at ask time and calibrate each family to 10 to 90 percent on Opus, because the no-brain cells matched or beat told-scoped in most families when every fact was readable in the world.
- Write corrections tasks whose signed records do not contradict the chat, because Opus often rejected the posted figure when signed records disagreed and told the asker to hold off.
