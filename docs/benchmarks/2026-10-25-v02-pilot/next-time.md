## Next time

### What we'd change if we ran this again

- Check each task's wording and exclusion patterns against correct replies before the cells run, because the pilot found one wording defect (`ms-03`) and two over-strict patterns (`ms-02`, `cr-04`) only afterwards, too late to fix in this run.
- Decide before the run whether a bot checking its own DM with the authorizer counts as a cross-scope read, because eight of nine failing `ar-03` trials in three cells did exactly that and the rule was settled only after the pilot.
- Count every number in the prose from the receipts, because the report first said 8 of 12 `ms-02` replies named the distractor ticket where the receipts say 6.

### Ideas to improve the eval

- Add a cell with memory turned off, because no cell disabled memory, so the pilot cannot say that any memory feature caused a pass.
- Read the records of held-out tasks for the same defects before they are sealed and preregistered, because that read found three defects in the 15 dev tasks and the held-out mirrors share some of the same pattern shapes.
