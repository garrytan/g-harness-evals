What happened:

1. The README's install command is `bun install -g github:garrytan/gbrain#stable`. I swapped in your pinned version, `#v0.60.757.0`. That tag exists on GitHub (commit 915e3b30). The current stable is v0.60.753.0, so 757 is newer than stable.
2. Bun 1.4.5 is installed at ~/.bun/bin/bun. The docs need 1.4.4 or newer. Their usual setup (`curl ... | bash`) was blocked for piping a remote script to the shell, so I took the binary from Bun's official release zip instead.
3. `bun install -g github:garrytan/gbrain#v0.60.757.0` was blocked by Hermes's package scanner. Its threat-intelligence lookups couldn't run (offline mode), and in single-query mode nobody is there to approve. The scanner said this is incomplete verification, not a sign the package is malicious.

The docs also offer `git clone --branch <tag>` + `bun install && bun link`, but I didn't use it, because that would just be routing around the same check.

To finish, either:

- Run it yourself:

    bun install -g github:garrytan/gbrain#v0.60.757.0
    gbrain --version
