    Embedding, reranking and query expansion are separate provider charges.

  1) conservative (in effect): 4K budget, up to 10 chunks, no reranker. Best for cost-sensitive or high-volume use.
  2) balanced: 12K budget, 25 chunks, reranked.
  3) tokenmax: no budget limit, 50 chunks, reranked. Recommended once you add a chat key.

  The reranker in balanced and tokenmax needs a Voyage key, so on this keyless brain they mostly just return bigger payloads. Expansion is off in every mode by default. To switch, run `/harness-state/.local/bin/gbrain config set search.mode <mode>`, then `gbrain search modes` to confirm.

Other settings in effect (nothing waits on these):
  - Auto-saving facts is off, so I save only what you ask me to remember. To turn it on: `gbrain config set memory.auto_writeback salient` (recommended).
  - Free background upkeep is on; turn it off with `gbrain config set maintenance.auto false`.
  - The conversation archive is on; with no key, nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.
  - Optional bundled skills were skipped; add them with `gbrain skillpack scaffold --all`.
  - Automatic event extraction is on by default but does nothing until a chat key exists; then each eligible page costs one paid call. Run `gbrain config set auto_chronicle false` to opt out now.

Without keys, search is keyword-only and duplicate detection catches exact repeats only. Adding a Voyage key enables semantic search and the reranker. Use the full path /harness-state/.local/bin/gbrain in commands, since it isn't on your PATH.
