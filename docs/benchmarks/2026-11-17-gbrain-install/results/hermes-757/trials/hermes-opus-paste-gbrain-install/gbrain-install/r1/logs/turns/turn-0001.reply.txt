I couldn't install GBrain, so nothing is set up and I have no remember/recall round trip to show you. Hermes's own security gate blocked the install. Since this is an unattended single-query run, it can't ask you to approve, so it refuses outright.

What got blocked:
1. Bun's official installer (`curl -fsSL https://bun.sh/install | bash`) was blocked because it pipes downloaded content into a shell. I used the guide's other Bun route instead, which worked: Bun 1.4.4 is now at /harness-state/.bun/bin/bun. Nothing else on the system was changed.
2. `bun install -g "github:garrytan/gbrain#v0.60.757.0"` was blocked because the package safety check runs offline and couldn't finish. The scanner says that is not evidence the package is malicious.
3. `git clone --branch v0.60.757.0 ...` was blocked because the scanner reads the tag "v0.60.757.0" as an IP address. That's a false positive, but it guards the same install.

I didn't try to get around these blocks, for example by downloading the tarball under another name. That would be dodging a safety control you haven't approved.

To proceed, do one of these:
- Run the install once yourself:
  `/harness-state/.bun/bin/bun install -g "github:garrytan/gbrain#v0.60.757.0"`
  and put `/harness-state/.bun/bin` on your PATH.
- Or allow it for unattended runs by setting `approvals.single_query_mode: approve` in config.yaml, then re-run this request.
- Or run this request in an interactive Hermes session, where you can approve each blocked command.

Once gbrain is installed, the rest of the plan stays memory-only and keyless:
- `gbrain init --pglite --no-embedding`
- Register it with Hermes using `printf 'Y\n' | hermes mcp add gbrain --env GBRAIN_HOME=$HOME --connect-timeout 60 --command $(which gbrain) --args serve --surface starter --advertise verbs`, then check it with `hermes mcp test gbrain`.
- Leave your SOUL.md, identity and instructions as they are.
- Verify with `gbrain doctor --only harness_wiring --json`, then remember an install-check note, recall it in a new process, check a keyword search, and forget the note.

  1) conservative: 4K token budget, at most 10 chunks, no reranker. This is the expected keyless default.
  2) balanced: 12K budget, 25 chunks, reranked.
  3) tokenmax: no budget, 50 chunks, reranked. Recommended when a chat API key is set.

You can switch any time with `gbrain config set search.mode <mode>`. Writeback (saving facts from conversations without being asked) and conversation capture start off, and upkeep starts on.
