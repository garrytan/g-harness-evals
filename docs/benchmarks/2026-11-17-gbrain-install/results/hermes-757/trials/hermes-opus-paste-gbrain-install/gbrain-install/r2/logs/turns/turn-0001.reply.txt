**Search mode (Step 3.5): `conservative` is in effect.** Setup picked it automatically because there is no chat key or reranker. You can change it any time:

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

  1) conservative (in effect): 4K budget, at most 10 chunks, no reranker. Best for cheap or high-volume use.
  2) balanced: 12K budget, 25 chunks, reranked. Reranking needs a provider key.
  3) tokenmax: no budget, 50 chunks, reranked. The widest retrieval.

To switch, run `gbrain config set search.mode <mode>`, then `gbrain search modes` to confirm. Search is keyword-only and nothing leaves this machine. These estimates are not what your own model subscription charges.
