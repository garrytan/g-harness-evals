   Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.

  1) conservative (in effect): 4K token budget, 10 chunks max, no reranker. Suits cheap models and high-volume use.

  3) tokenmax: no budget, 50 chunks, reranked. The widest retrieval.

To switch: `/harness-state/.local/bin/gbrain config set search.mode <mode>`. Query expansion is off by default in every mode.
