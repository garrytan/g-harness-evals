Search-mode choice. Install set the mode to conservative because there's no chat key and no reranker. The cost estimates below are the matrix from this release's install output. The install guide's own copy shows older, higher prices.

                       Haiku 5.5     Sonnet 5.5    Opus 5.5
                       ($0.10/M in)  ($2/M in)     ($4/M in)
       conservative    $4/mo         $80/mo        $160/mo

       Assumed payload: conservative 4K, balanced 10K, tokenmax 20K tokens.
       Scales linearly: x10 for 100K/mo, /10 for 1K.

  1) conservative (in effect): 4K token budget, at most 10 chunks.
  2) balanced: 12K budget, 25 chunks. Its reranker needs a key, so it can't run yet.
  3) tokenmax: no budget, 50 chunks.

Since the brain is keyless, `gbrain search` and recall never expand queries and nothing goes to a cloud provider. To change the mode: `gbrain config set search.mode <mode>`, then check with `gbrain search modes`.

Other first-run settings, defaults in effect:
- Auto-saving facts is off: it saves only what you ask. "salient" is the recommended option (`gbrain config set memory.auto_writeback salient`).
- Free upkeep is on.
- The conversation archive is on; turn it off with `gbrain transcripts archive off`.
- No services, cron jobs or paid providers were set up.

Two things to know about the agent's memory tools:
- Facts saved by the agent must name an existing page with its folder (e.g. `install-check/note`). A plain name is refused if no page has it.
- The memory tools Hermes uses don't accept the field that marks where a fact came from (`content_origin`); saves work without it.
