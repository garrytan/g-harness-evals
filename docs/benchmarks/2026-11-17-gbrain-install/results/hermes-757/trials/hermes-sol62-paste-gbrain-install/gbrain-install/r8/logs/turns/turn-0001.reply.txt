Search mode: conservative is active. It uses a 4K token budget and up to 10 chunks, with no reranker. Balanced allows 12K tokens and 25 chunks; tokenmax has no token cap and allows 50 chunks. The latter two can rerank if you configure a provider. Choosing a mode does not add a key.
