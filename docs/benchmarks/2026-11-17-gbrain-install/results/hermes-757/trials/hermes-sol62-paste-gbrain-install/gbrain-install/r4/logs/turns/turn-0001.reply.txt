Search mode is conservative: keyword-only, a 4K token budget, up to 10 chunks, and no reranker. Balanced allows 12K tokens and 25 chunks; tokenmax has no token cap and allows 50 chunks. Neither can rerank without a configured provider.

Automatic fact saving is off. Idle upkeep and the local redacted conversation archive are on by default. To disable the archive, run /harness-state/.local/bin/gbrain transcripts archive off. GBrain itself stays local in this setup, but memories recalled into chat are sent to Hermes’s configured model. Hosted GBrain at gbrain.io is an optional paid alternative; it wasn’t enabled.
