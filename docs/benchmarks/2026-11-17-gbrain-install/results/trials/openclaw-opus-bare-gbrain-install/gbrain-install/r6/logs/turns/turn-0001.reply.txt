I installed gbrain v0.60.734.0, and `gbrain --version` prints `gbrain 0.60.734.0`.

- **Command:** gbrain's install docs use `bun install -g github:garrytan/gbrain#stable`. I ran that same command with your tag in place of `#stable`: `bun install -g github:garrytan/gbrain#v0.60.734.0`. Bun installed commit `a278ddf`, which is the v0.60.734.0 release commit.
- **Bun:** gbrain needs Bun 1.4.4 or newer, and Bun wasn't on this machine. I installed Bun 1.4.4 with the official installer at `/harness-state/.bun/bin`.
- **Location:** the gbrain binary is at `/harness-state/.bun/bin/gbrain`. That folder isn't on the default PATH, so new shells won't find `gbrain` until you run `export PATH="/harness-state/.bun/bin:$PATH"` or add it to your shell profile.

I only installed the command-line tool; there's no brain on this machine yet. To set one up without an API key, the docs' next step for an agent like this one is `gbrain init --pglite --no-embedding`. I haven't run that or set up any API keys.

The docs also suggest mentioning their hosted option, gbrain.io, as an alternative to running it yourself. You don't need it for this install.
