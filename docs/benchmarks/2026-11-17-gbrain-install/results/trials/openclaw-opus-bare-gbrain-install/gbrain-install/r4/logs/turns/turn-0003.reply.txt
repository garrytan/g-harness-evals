gbrain is now connected to OpenClaw, using gbrain's recommended settings. It's still free with no API keys.

**What I changed:**
- **Connected to OpenClaw:** I added gbrain to OpenClaw's tool servers, following gbrain's own OpenClaw guide. No gateway restart was needed. I ran the same startup command by hand and it offered the expected memory tools: `remember`, `recall`, `forget`, `entity`, `synthesize`, `context_pack`, `delta` and `request_tools`. Not verified: those tools didn't appear inside this conversation yet. They should show up in OpenClaw's next session.
- **Saving facts:** I turned on gbrain's recommended setting, so agents now save lasting facts you state, like preferences, decisions and commitments, and record where each came from. To go back to saving only what you ask: `gbrain config set memory.auto_writeback off`.
- **PATH:** I added `~/.bun/bin` to `~/.bashrc` and `~/.profile`, so `gbrain` works in new terminals.

**Left alone on purpose:**
- **ClawHub plugin:** I didn't install the `gbrain` plugin from ClawHub. gbrain's docs say that one is an old, unofficial upload and won't install.
- **Context engine:** I didn't make gbrain OpenClaw's context engine, the plugin slot that would route every conversation through gbrain. That's optional, and the plain tool connection covers memory.

Nothing is waiting on you. Everything still stays on this machine, as before.
