gbrain is set up with the free defaults and no API keys. It's connected to OpenClaw, but the running Gateway still needs a restart, which I couldn't do from here.

**What I did:**
- **Brain:** created a local brain at `/harness-state/.gbrain/brain.pglite` using the docs' default (`gbrain init --pglite --no-embedding`). It uses keyword search only, so nothing is sent to any paid provider.
- **MCP server:** registered `gbrain` in OpenClaw's config (`mcp.servers.gbrain`) with the command the docs give. OpenClaw said this applies without a restart.
- **Brain-first rule:** `gbrain setup openclaw` wrote a marked block into `/workspace/AGENTS.md` telling the agent to check GBrain first. It also installed and enabled a small plugin, `gbrain-turn-rule`, which repeats that rule on every turn. Inspecting the plugin from the command line shows it loaded with its hook.
- **PATH:** added `~/.bun/bin` to `~/.profile` and `~/.bashrc`.
- **Checks:** I saved a test fact and recalled it successfully, then withdrew it. `gbrain doctor` gives an overall health score of 90/100. Its separate brain score is 25/100, which is expected for an empty brain with no embeddings.

**Settings in effect** (change any of them later with the command shown):
- **Search mode: conservative.** gbrain picked it automatically because there's no API key. To switch, run `gbrain config set search.mode balanced` or `tokenmax`. gbrain's cost table for the text it retrieves, at 10K queries a month (Haiku / Sonnet / Opus):
  - conservative: $4 / $80 / $160
  - balanced: $10 / $200 / $400
  - tokenmax: $20 / $400 / $800
- **Auto-saving facts: off.** Agents save only what you ask them to remember. gbrain recommends `gbrain config set memory.auto_writeback salient`, which saves important facts you state.
- **Free upkeep: on.** Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive: on.** gbrain keeps one redacted page per conversation per day, and with no keys nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.

The pinned-release warning from before still applies. gbrain may update itself on the stable channel and move off v0.60.734.0. gbrain also offers a hosted version at gbrain.io. I skipped it to keep everything local and free.
