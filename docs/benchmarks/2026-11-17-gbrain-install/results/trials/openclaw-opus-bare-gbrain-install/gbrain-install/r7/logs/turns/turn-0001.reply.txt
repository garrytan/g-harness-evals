I installed gbrain v0.60.734.0 and it runs: `gbrain --version` prints `gbrain 0.60.734.0`.

- **What I ran:** gbrain's README gives `bun install -g github:garrytan/gbrain#stable`. I used that command with your tag swapped in: `bun install -g github:garrytan/gbrain#v0.60.734.0`.
- **Same as stable today:** the `stable` tag points to the same commit as v0.60.734.0 (`a278ddf`), so this is the current stable release, pinned to that version.
- **Bun:** gbrain needs Bun 1.4.4 or newer, and the machine didn't have it. I installed Bun 1.4.4 with the official script.
- **Location:** the `gbrain` command is at `/harness-state/.bun/bin/gbrain`.
- **PATH:** Bun's installer didn't add `~/.bun/bin` to `~/.bashrc` or `~/.profile`. You'll need to run `export PATH="$HOME/.bun/bin:$PATH"` in new shells, or add that line to your shell startup file.
- **No brain set up yet:** `gbrain doctor` stops with `no_brain`, which is expected because none has been created. It suggests `gbrain init --pglite --no-embedding` to make a local one. I can run that, or connect to Postgres or a hosted brain instead.

gbrain also says this install follows the stable channel, so any upgrades will come from stable. It won't upgrade without your say-so unless you turn on automatic upgrades.
