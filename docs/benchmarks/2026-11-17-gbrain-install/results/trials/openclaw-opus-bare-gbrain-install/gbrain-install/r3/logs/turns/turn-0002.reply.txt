gbrain is set up with free defaults and no API keys, and OpenClaw (this assistant) is connected to it. The gbrain tools will show up from my next turn.

**What I did:**
1. **Created the brain:** I ran `gbrain init --pglite --no-embedding`. The brain is stored locally at `~/.gbrain/brain.pglite`, and nothing is sent to any outside service.
2. **Tested memory:** I saved a test fact with `gbrain remember` and got it back with `gbrain recall`. Then I removed the test fact with `gbrain forget`.
3. **Connected it to OpenClaw:** I added `gbrain` to OpenClaw's MCP server config, using the command the docs give for OpenClaw: `gbrain serve --surface starter --advertise verbs`. OpenClaw's connection check found the server with 8 tools: the seven memory commands plus one for finding more. Its setup check says ok. I reloaded the MCP settings, so no gateway restart was needed.

**Settings in effect (all gbrain's own defaults):**
- **Search:** keyword-only, because there's no embedding key. A fact worded differently from what was saved may not be found, and only exact duplicates are caught.
- **Search mode:** conservative, which keeps the amount of text pulled in per search small. You can change it with `gbrain config set search.mode balanced|tokenmax`, but balanced is meant to use a re-ranking step that won't run without an API key.
- **Automatic saving:** off, so agents only save what you ask them to remember. gbrain recommends `gbrain config set memory.auto_writeback salient` for a personal brain, which saves lasting facts you state, with a note of where each came from. It's opt-in, so I left it off.
- **Free upkeep:** on. It runs while an agent has gbrain open, and nothing is deleted or charged without you. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. gbrain keeps one redacted page per conversation per day from agent sessions, and without an API key that stays on this machine. Turn it off with `gbrain transcripts archive off`.

The pinned v0.60.734.0 install hasn't changed, and it only moves to a newer version if you run `gbrain upgrade` or turn on automatic upgrades.
