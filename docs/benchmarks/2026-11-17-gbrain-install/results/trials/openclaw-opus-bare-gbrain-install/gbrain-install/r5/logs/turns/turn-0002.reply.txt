gbrain is installed and connected to OpenClaw, using a free local brain with no API keys. One step is left: the gateway needs a restart before the per-turn "check GBrain first" rule takes effect, and I couldn't do that from this session.

**What's set up:**
- **Brain:** a local brain in `~/.gbrain` with no embeddings, so search is keyword-only and nothing leaves this machine. I saved a test fact and recalled it, and `gbrain doctor` scored the brain 100/100.
- **PATH:** I added `~/.bun/bin` to a new `~/.bashrc`, so new shells will find `gbrain`.
- **MCP server:** OpenClaw now has a `gbrain` MCP server entry. I started the server by hand and it lists its memory tools: `remember`, `recall`, `forget`, `entity`, `delta`, `synthesize`, `context_pack` and `request_tools`.
- **Brain-first instructions:** gbrain created `/workspace/AGENTS.md` with a short marked block telling the agent to check gbrain before answering. Text outside the markers is left alone.
- **Per-turn rule plugin:** the `gbrain-turn-rule` plugin is installed and enabled, with the conversation-access setting it needs. OpenClaw reports it as loaded with its `before_prompt_build` hook.

**Still open:**
- **Gateway restart:** the OpenClaw system tool refused the restart and said to start a new conversation. You can do it from a fresh chat or with `/restart`. The MCP entry was supposed to apply without a restart, but the gbrain tools still didn't show up in this session's tool search, so I haven't confirmed the gateway can use it.
- **gbrain's setup warning:** after installing the plugin, `gbrain setup` ended with a "hook not loaded" error, both times I ran it. OpenClaw's own check says the hook is loaded. I think gbrain looks at a different, empty field in that report, so the warning is likely a false alarm, but I haven't proven that. If the "check GBrain first" note doesn't appear on turns after the restart, the fix is `gbrain setup openclaw --instructions-only --workspace /workspace`.

**Defaults left on (gbrain's choices):** conservative search, and the agent saves only what you ask it to remember. Free background upkeep runs while the gbrain server is up. A conversation archive keeps one redacted page per conversation per day; turn it off with `gbrain transcripts archive off`.
