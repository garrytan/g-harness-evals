I installed gbrain v0.60.734.0. In the docs' install command (`bun install -g github:garrytan/gbrain#stable`), I swapped `#stable` for your tag and ran `bun install -g github:garrytan/gbrain#v0.60.734.0`.

- **Bun:** wasn't installed, so I first installed Bun 1.4.4, the minimum version the docs require.
- **Check:** `gbrain --version` prints `gbrain 0.60.734.0`. The commit it installed (`a278ddf`) is the one the `v0.60.734.0` tag points to.
- **Binary:** it's at `/harness-state/.bun/bin/gbrain`. That folder isn't on your PATH by default, so run `export PATH="$HOME/.bun/bin:$PATH"` or add that line to your shell profile.

This only installs the command-line tool. You don't have a brain (gbrain's memory store) yet. To make a local one that needs no API key, the docs give `gbrain init --pglite --no-embedding`.

The docs also point to a hosted version at gbrain.io if you'd rather not run it yourself.
