**Two things worth knowing**

- `#stable` is a moving branch, not a version — I pinned the exact tag as you asked, so this install stays on 0.60.734.0 through `bun update`. Only `gbrain upgrade` moves it, so don't run that while you want to stay pinned. To silence update notices: `gbrain config set self_upgrade.mode off`.
- This is a standalone CLI/daemon, **not** an OpenClaw plugin — nothing to register via `openclaw plugins`, and no local brain was created (CLI only, as the docs' default install does).

Also note `~/.bun/bin` isn't on this shell's default `PATH`; start future `gbrain` calls with `export PATH="$HOME/.bun/bin:$PATH"` or add it to the shell rc.
