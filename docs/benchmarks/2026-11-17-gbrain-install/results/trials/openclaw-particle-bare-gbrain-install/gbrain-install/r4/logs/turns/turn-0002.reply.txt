**Defaults I chose, and why**

- **Auto-writeback: off** (product default). I only save facts when you ask. Turning it on (`gbrain config set memory.auto_writeback salient`) is the one default I'd consider changing later — it's local-only here, so it costs nothing.
- **Free upkeep: on** (local maintenance tier).
- **Conversation archive: I turned it off.** This gateway serves a channel, so auto-archiving one page per conversation/day into shared brain memory could capture other people's messages. `gbrain transcripts archive on` restores it if this is really a solo channel.
- **Skill scaffolding: skipped.** `gbrain skillpack scaffold --harness openclaw` refused pending a "shared-skills follow approval" and independently flagged the same multi-person caveat (an unbound brain token reads every source regardless of who's talking). Memory works without it; I didn't force an approval cycle on your behalf.
