**Settings now in effect** (defaults, all changeable)
- **Search mode: conservative** — tight 4K retrieval budget, needed because there's no chat key or reranker. Change with `gbrain config set search.mode balanced|tokenmax`.
- **Writeback: off** — agents save only what you explicitly ask them to remember. `salient` is the recommended opt-in: `gbrain config set memory.auto_writeback salient`.
- **Upkeep: on** — free upkeep runs only while a gbrain session is open; nothing deleted or paid. Off: `gbrain config set maintenance.auto false`.
- **Conversation archive: on** — one redacted page per conversation per day, local only. Off: `gbrain transcripts archive off`.

Cost matrix for search modes, per the installer (downstream payload cost at 10K queries/mo):

```
                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
