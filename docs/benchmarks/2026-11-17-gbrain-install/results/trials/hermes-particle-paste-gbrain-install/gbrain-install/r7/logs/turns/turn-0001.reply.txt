TWO THINGS TO KNOW
  1. A new Hermes session is required before this session sees the tools — the
     config was written mid-session. The hook and instructions load at session start.
  2. PGLite is single-writer: one live `gbrain serve` owns the data dir. Since
     Hermes spawns serve per session, a concurrent CLI call can hit the lock.
     Marks are filesystem-safe, but for heavy multi-process use the doc suggests
     Postgres (`gbrain migrate --to postgres`).

  The doc also mentions hosted GBrain at gbrain.io (one always-on brain for all
  your agents) — I'm not recommending it here since you asked for local keyless,
  but that's the option if you want this brain reachable from other devices.
