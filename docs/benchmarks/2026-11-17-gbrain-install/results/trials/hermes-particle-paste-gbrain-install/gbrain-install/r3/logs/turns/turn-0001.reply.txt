  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.

 1) conservative — 4K budget, 10 chunks, no reranker. Now in effect. Best fit here since nothing can rerank.

 3) tokenmax — no budget, 50 chunks, reranked. Widest retrieval, but without a chat key it buys payload size, not better ranking.
