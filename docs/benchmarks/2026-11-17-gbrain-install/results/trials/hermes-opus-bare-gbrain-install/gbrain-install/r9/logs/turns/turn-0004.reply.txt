To connect it, add this to the end of `/harness-state/hermes/config.yaml` (these are the docs' recommended settings):

```
mcp_servers:
  gbrain:
    command: /harness-state/.bun/bin/gbrain
    args: [serve, --surface, starter, --advertise, verbs]
    env:
      GBRAIN_HOME: /harness-state
    connect_timeout: 60.0
    enabled: true
```

Then, optionally, run `gbrain setup hermes --instructions-only`. It adds a note to `SOUL.md` and a short per-turn reminder to `config.yaml`, telling Hermes to check gbrain before answering. Start a new Hermes session after either step.
