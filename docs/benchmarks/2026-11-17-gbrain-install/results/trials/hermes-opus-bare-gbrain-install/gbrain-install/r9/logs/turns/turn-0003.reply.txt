gbrain v0.60.734.0 is ready to use. It's on a free, local-only setup with no API keys.

- **PATH:** There was no `~/.bashrc`, so I created one that adds `~/.bun/bin` to your PATH. New shells will find `gbrain`. I couldn't open a fresh shell here to confirm it, but `gbrain --version` still prints `0.60.734.0`.
- **Test fact:** I withdrew the test fact (#1) with `gbrain forget 1`, so the brain is empty again. Withdrawn means it no longer appears in recall, but the text stays in gbrain's history and backups, and that exact wording can't be saved again.
- **Settings:** I kept the defaults from setup. That's a local database with keyword search only, conservative search mode, and agents saving only what you ask them to remember. Free background upkeep and the redacted daily conversation archive are both on. Nothing leaves this machine.
