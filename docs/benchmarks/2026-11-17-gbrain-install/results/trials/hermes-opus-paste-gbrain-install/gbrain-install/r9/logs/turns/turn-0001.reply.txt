Search mode: conservative is in effect, chosen automatically because there's no chat or reranker key. It controls how much retrieved text goes to the model per query, and you can change it any time:

Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.

  1) conservative (in effect): 4K token budget, up to 10 chunks, no reranker. Suits Haiku subagents, cost-sensitive setups and high-volume loops.
  2) balanced: 12K budget, up to 25 chunks, reranked. The reranker needs a VOYAGE_API_KEY.
  3) tokenmax: no budget cap, up to 50 chunks, reranked. The widest retrieval; recommended once you have a chat key.

To switch: `gbrain config set search.mode <mode>`. To check what's running: `gbrain search modes`. Queries are never expanded by default, and a keyless brain never expands.

Other settings in effect (none needs an answer):
