Search mode: GBrain picked conservative automatically because there are no keys. Which one do you want? This is the cost table from the install guide (estimated cost per month at 10K queries):

                  Haiku 4.5     Sonnet 4.6    Opus 4.7
                  ($1/M)        ($3/M)        ($5/M)
  conservative    $40/mo        $120/mo       $200/mo
  balanced        $100/mo       $300/mo       $500/mo
  tokenmax        $200/mo       $600/mo       $1,000/mo

  1) conservative (in effect now): 4K token budget, up to 10 results. Best for cheap or high-volume setups.
  2) balanced: 12K budget, up to 25 results. Its reranker can't run without a key, so it adds little here.
  3) tokenmax: no budget, up to 50 results. Best for frontier models.

This release's own setup prints lower numbers: conservative $4 / $80 / $160, balanced $10 / $200 / $400, tokenmax $20 / $400 / $800 per month (Haiku / Sonnet / Opus 5.5). To switch, run `gbrain config set search.mode <mode>`, then `gbrain search modes` to confirm.
