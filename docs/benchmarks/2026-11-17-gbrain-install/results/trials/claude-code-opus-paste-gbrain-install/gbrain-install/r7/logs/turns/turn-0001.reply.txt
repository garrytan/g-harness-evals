## Search mode: currently `conservative` (you can change it any time)
It was picked automatically because there's no chat key and no reranker.
```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
1. **conservative** (in effect): 4K-token budget, at most 10 chunks, no reranker. Best for Haiku subagents, cost-sensitive setups and high-volume loops.
2. **balanced:** 12K budget, 25 chunks, reranked. The reranker needs a key, which this brain doesn't have yet.
3. **tokenmax:** no budget, 50 chunks, reranked. The widest retrieval, recommended once a chat key is set.

`gbrain query` never expands queries by default in any mode; `--expand` forces it. Since this agent runs on Opus, the mode makes a real difference to cost. To switch, run `gbrain config set search.mode <mode>` or just tell me which one you want.

## Other settings in effect
- **Automatic saving (writeback):** off. I save only what you ask me to remember. GBrain recommends `salient` (durable facts you state, saved with provenance); turn it on with `gbrain config set memory.auto_writeback salient`.
- **Free upkeep:** on while the session is open. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and nothing leaves this machine without an embedding key. Turn it off with `gbrain transcripts archive off`.
- **Report back (Wakeshift):** off. Turn it on with `gbrain wakeshift enable`.
- **Hosted option:** gbrain.io runs GBrain for you, with nothing to keep online, and can import this brain: https://gbrain.io/?ref=cli-setup
