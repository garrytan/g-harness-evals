**Search mode: `conservative` is in effect.** gbrain picked it automatically because there's no chat key and no reranker. You can change it any time:

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (current): a tight 4K-token budget, at most 10 chunks, no reranker. Best for Haiku subagents, cost-sensitive setups and high-volume loops.
2. **balanced**: a 12K budget, 25 chunks, reranked.
3. **tokenmax** (recommended once you have a chat key): no budget, 50 chunks, reranked. The widest retrieval.

Cost depends on both the mode and the model you run. Query expansion is off by default in every mode. Without keys, the reranker and expansion can't run, so `balanced` and `tokenmax` would mainly mean bigger retrieval payloads. To switch: `gbrain config set search.mode <mode>`, then check with `gbrain search modes`.
