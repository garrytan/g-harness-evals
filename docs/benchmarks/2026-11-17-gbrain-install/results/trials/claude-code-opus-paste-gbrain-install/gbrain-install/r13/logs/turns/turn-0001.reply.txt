```
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative:** tight 4K budget, at most 10 results, no reranker. Best for cheap setups and high-volume loops.
2. **balanced:** 12K budget, 25 results, reranked. The reranker needs a provider key, so it won't run while you stay keyless.
3. **tokenmax:** no budget, 50 results, reranked. The widest retrieval, recommended once you add a chat key.

Cost depends on both the mode and the model you run. To change it: `gbrain config set search.mode <mode>`.
