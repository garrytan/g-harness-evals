```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (current): tight 4K-token budget, at most 10 chunks, no reranker. Best for Haiku subagents, cost-sensitive setups and high-volume loops.
2. **balanced:** 12K budget, 25 chunks, reranked. The reranker needs a provider key, so this only pays off once you add one.
3. **tokenmax** (recommended once you have a chat key): no budget, 50 chunks, reranked. The widest retrieval.

Query expansion is off by default in every mode. Cost depends on both the mode and the model you run, and these are API list prices, not what your subscription charges. To switch, run `gbrain config set search.mode <mode>`, or just tell me and I'll do it.
