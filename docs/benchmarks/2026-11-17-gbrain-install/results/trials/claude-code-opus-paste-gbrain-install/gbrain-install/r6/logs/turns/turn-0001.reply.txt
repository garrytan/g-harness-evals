```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5

  conservative    $4/mo         $80/mo        $160/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.

  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (current): tight 4K budget, at most 10 chunks, no reranker. Best for Haiku subagents, cost-sensitive setups and high-volume loops.
2. **balanced**: 12K budget, 25 chunks, reranked.
3. **tokenmax**: no budget, 50 chunks, reranked. The widest retrieval; recommended once you have a chat key.

The reranking in balanced and tokenmax needs a provider key, and this brain has none. Query expansion is off in every mode; `--expand` turns it on for one call, and `gbrain config set search.expansion true` makes it the default. Change the mode any time with `gbrain config set search.mode <mode>`, or tell me and I'll do it.
