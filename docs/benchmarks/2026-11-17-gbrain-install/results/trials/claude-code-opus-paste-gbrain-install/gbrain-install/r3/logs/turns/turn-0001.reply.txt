## Search mode: **conservative** (applied automatically)
GBrain picked conservative because no chat key or reranker is configured.

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative (current):** about 4K tokens per lookup, at most 10 results, no reranking. Good for cost-sensitive or high-volume use.
2. **balanced:** about 12K tokens and up to 25 results, re-sorted by a reranker. The reranker needs a provider key, so it can't run yet.
3. **tokenmax:** no token limit and up to 50 results, reranked. The widest retrieval; it's the recommended mode once a chat key is set.

These figures estimate what your downstream model pays to read the retrieved text, not a price for your subscription. Query expansion is off by default in every mode. To switch, run `gbrain config set search.mode <mode>`, then check with `gbrain search modes`.
