1. **conservative** (in effect): 4K-token budget, at most 10 chunks, no reranker. Suits Haiku-class models, tight budgets and high-volume loops.
2. **balanced:** 12K budget, 25 chunks, reranked. The reranker needs a provider key; you have none now.
3. **tokenmax:** no budget, 50 chunks, reranked. Widest retrieval; recommended once you add a chat key.

These are estimates of the input cost to the model that reads the results, not prices for your Claude subscription. To switch, run `gbrain config set search.mode <mode>` and check with `gbrain search modes`.
