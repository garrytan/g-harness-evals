## Search mode: choose any time
GBrain picked **`conservative`** because there's no chat key and no reranker. `gbrain search modes` confirms it.

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative (in effect):** 4K token budget, at most 10 chunks, no reranker. Best for cost-sensitive or high-volume use.
2. **balanced:** 12K budget, 25 chunks, reranked. It needs a reranker key to rerank.
3. **tokenmax:** no budget, 50 chunks, reranked. This is the widest retrieval, recommended once a chat key is set.

To change it: `gbrain config set search.mode <mode>`. Query expansion is off by default in every mode. These figures estimate what the retrieved text costs your model to read; they aren't what your Claude subscription charges.

## Other settings in effect
- **Automatic saving:** off, so I save only what you ask me to remember. GBrain recommends `gbrain config set memory.auto_writeback salient`, which saves lasting facts you state, with their source.
- **Upkeep:** a free maintenance pass runs while a session is open. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and with no keys nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.
- **Starter pages (optional):** `gbrain setup claude-code --shape personal` (or `company` / `both`) adds empty starter pages. Without it, memory works as is.
- **Hosted option:** gbrain.io runs GBrain for you and can import this brain (https://gbrain.io/?ref=cli-setup).
