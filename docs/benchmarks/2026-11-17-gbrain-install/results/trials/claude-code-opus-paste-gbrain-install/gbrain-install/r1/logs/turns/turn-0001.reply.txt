**Search mode: `conservative` (applied automatically)**
It was chosen because there's no chat key and no reranker, so a reranked mode couldn't run. The mode sets how much retrieved text goes into each answer, and you can change it any time.

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (in effect): 4K budget, up to 10 chunks, no reranker. Best for cost-sensitive or high-volume use.
2. **balanced:** 12K budget, 25 chunks, reranked. The reranker needs a Voyage key.
3. **tokenmax** (recommended with a chat key): no budget, 50 chunks, reranked. The widest retrieval.

To switch, run `gbrain config set search.mode <mode>` and check it with `gbrain search modes`. `gbrain query` only expands queries with `--expand`. `gbrain search` and the memory commands never expand. These prices are estimates of what the downstream model reads, not your subscription's billing.
