**Search mode (Step 3.5):** it was set automatically to **`conservative`**, because there's no chat key and no reranker.

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (in effect): tight 4K budget, 10 chunks at most, no reranker. Best for Haiku subagents, cost-sensitive setups and high-volume loops.
2. **balanced:** 12K budget, 25 chunks, reranked.
3. **tokenmax** (recommended once you have a chat key): no budget, 50 chunks, reranked. The widest retrieval.

These figures are estimates of what the retrieved text costs as input to the model; they aren't what you pay for your harness subscription. Cost depends on both the mode and the model you run. Since this agent runs on Opus 5.5, that's the right-hand column. Reranking needs a provider key, so `balanced` won't rerank until you add one. Query expansion is off in every mode by default; `--expand` turns it on for one query. To change the mode: `gbrain config set search.mode <mode>`, then check with `gbrain search modes`.
