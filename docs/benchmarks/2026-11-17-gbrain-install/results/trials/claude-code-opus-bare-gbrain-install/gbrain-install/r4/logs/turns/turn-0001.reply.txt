**Things to know**
- **PATH:** `~/.bun/bin` isn't on your PATH in new shells yet. Run `export PATH="$HOME/.bun/bin:$PATH"` or add that line to your shell profile.
- **Update channel:** the first time it ran, gbrain said it now "follows the stable channel." According to the README, it won't install updates unless you approve them or turn on automatic upgrades. Leave automatic upgrades off if you want to stay on this version.
- **No brain yet:** I only installed the command-line tool. `gbrain doctor` currently reports `no_brain`, which is expected at this stage. The docs' next step is one of:
  - `gbrain setup claude-code` (or `gbrain setup codex`): creates a brain and connects it to your agent. It writes MCP config, hooks and an instruction block into `~/.claude/CLAUDE.md`, and `--dry-run` shows the changes first.
  - `gbrain init --pglite --no-embedding`: creates a local brain without connecting it to any agent.
