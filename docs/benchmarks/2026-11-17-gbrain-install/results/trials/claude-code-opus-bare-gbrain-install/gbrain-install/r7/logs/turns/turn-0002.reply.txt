I set gbrain up with free, keyless defaults and connected it to Claude Code. It works now: a test fact I saved came back when I searched for it. It's set to expire after a day.

**What I ran:** `gbrain setup claude-code`, after previewing it with `--dry-run`. It:
- Created a local brain at `~/.gbrain/brain.pglite`. It needs no database server and no API keys.
- Registered gbrain as a tool server in Claude Code for all your projects. `claude mcp get gbrain` shows it as **✔ Connected**.
- Added two hooks to `~/claude/settings.json` that give each session context from the brain at start and on every prompt.
- Created `~/claude/CLAUDE.md` with an instruction for agents to check the brain first.

It turned on no paid providers, no API keys and no transcript capture.

**Health check:** `gbrain doctor` scores 95/100. Its only warning says Claude Code has no gbrain registration, but that's wrong: the check couldn't confirm the registration from where it ran, and Claude Code itself shows gbrain as connected.

**Settings in effect** (each can be changed later with one command):

| Setting | Current | To change |
|---|---|---|
| Search mode | `conservative`, chosen because there are no API keys | `gbrain config set search.mode balanced` or `tokenmax` |
| Automatic saving of facts you state | off: agents save only what you ask them to remember | `gbrain config set memory.auto_writeback salient` (gbrain's recommended option) |
| Free background upkeep | on | `gbrain config set maintenance.auto false` |
| Conversation archive | on: one redacted page per conversation per day, kept on this machine | `gbrain transcripts archive off` |
| Starter pages | none | `gbrain setup claude-code --shape personal` |

**Limitations without keys:** search is keyword-only. Saving only catches exact duplicates, so the same fact reworded can be stored twice.

**Next step for you:** open a new Claude Code session, since the config is only read at startup, and check that `/mcp` lists gbrain.
