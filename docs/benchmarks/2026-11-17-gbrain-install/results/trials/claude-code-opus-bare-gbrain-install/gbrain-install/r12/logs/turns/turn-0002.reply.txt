gbrain is set up with a free local brain and connected to Claude Code. It uses no API keys and no paid services. Open a new Claude Code session to pick it up, then check that `/mcp` lists gbrain.

**What `gbrain setup claude-code` did** (I ran a dry run first to preview it):
- It created the brain at `/harness-state/.gbrain/brain.pglite`. This is PGLite, a database stored in that file, so no server runs. Search is keyword-only.
- It registered the gbrain MCP server in `/harness-state/claude/.claude.json`, and `claude mcp get gbrain` shows it as **Connected**.
- It added SessionStart and UserPromptSubmit hooks in `/harness-state/claude/settings.json`. These load relevant memory into each session.
- It created `/harness-state/claude/CLAUDE.md`, which tells Claude to check the brain first.
- Its own check passed: the MCP server responded, listed 8 tools and answered a memory lookup.
- It left capture of whole session transcripts and paid AI services off.

`gbrain doctor` scored the install 95/100. Its one warning says Claude Code has no gbrain registration, but that's wrong here: the warning itself says it couldn't check from this process, and the registration exists and connects.

**Settings in effect** (all defaults; change them any time):
- **Search mode:** conservative, which suits a setup with no keys. Other options are `gbrain config set search.mode balanced` or `tokenmax`.
- **Saving facts automatically:** off, so only what you ask it to remember is saved. gbrain recommends `gbrain config set memory.auto_writeback salient`, which saves lasting facts you state, such as preferences and decisions.
- **Upkeep:** free background maintenance runs while a session is open. To turn it off: `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and with no keys nothing leaves this machine. To turn it off: `gbrain transcripts archive off`.
- **Release channel:** stable, meaning weekly releases promoted after testing. Use `gbrain config set self_upgrade.channel alpha` to get every release.
- **Starter pages:** none. For a personal brain with three empty starter pages: `gbrain setup claude-code --shape personal`.

You can remove the gbrain configuration added to Claude Code with `gbrain setup claude-code --remove`. Hosted gbrain (gbrain.io) can also import this brain if you'd rather not run it locally.
