- **Bun:** the docs require Bun 1.4.4 or newer, so I installed Bun 1.4.4 with the official script. It's in `~/.bun/bin`.
- **gbrain:** I ran the README's install command with the version tag in place of `#stable`: `bun install -g github:garrytan/gbrain#v0.60.734.0`. That resolved to commit `a278ddf`.
- **PATH:** your shell profile doesn't add `~/.bun/bin` to PATH yet, so run `export PATH="$HOME/.bun/bin:$PATH"` in a new shell before using `gbrain`.
