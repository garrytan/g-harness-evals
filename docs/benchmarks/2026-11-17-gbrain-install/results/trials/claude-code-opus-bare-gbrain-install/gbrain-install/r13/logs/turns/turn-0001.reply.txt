I installed gbrain v0.60.734.0, and `gbrain --version` prints `gbrain 0.60.734.0`.

- **Bun:** it wasn't installed, so I installed Bun 1.4.4 (the minimum the docs ask for) with the official installer.
- **gbrain:** I ran `bun install -g github:garrytan/gbrain#v0.60.734.0` instead of the docs' `#stable`. It installed commit `a278ddf`, which is the commit the `v0.60.734.0` tag points to.
- **PATH:** the Bun installer didn't add itself to your shell profile, so I added `~/.bun/bin` to `~/.bashrc`. New shells will find `gbrain`; a shell that's already open needs `export PATH="$HOME/.bun/bin:$PATH"` first.

This installs only the command-line tool, with no brain set up yet. The docs' next step is `gbrain setup claude-code` (or `gbrain setup codex`), which creates a local brain with no API key and connects it to the agent. It also writes instructions into `~/.claude/CLAUDE.md`, so I didn't run it without asking. If you'd rather not run a brain yourself, the docs also point to the hosted version at gbrain.io.
