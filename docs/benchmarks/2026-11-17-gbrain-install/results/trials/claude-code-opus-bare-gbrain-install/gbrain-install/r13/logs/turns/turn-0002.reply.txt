gbrain is set up as a free local brain connected to Claude Code, with no API keys. Its built-in test passed: the connection started, listed 8 memory tools and answered a recall. `claude mcp get gbrain` also shows it as **Connected**.

**What I ran:** `gbrain setup claude-code` with its defaults, after a dry run to check what it would write. It created and changed:
- a local brain at `~/.gbrain/brain.pglite`, which needs no server and no embedding key
- a `gbrain` memory-tool server entry in `~/.claude/.claude.json`
- two hooks in `~/.claude/settings.json` that pull in memory context when a session starts and when you send a message
- a short rule in a new `~/.claude/CLAUDE.md` telling the agent to check the brain first

It left off transcript capture and paid providers.

**To use it:** start a new Claude Code session, because this one won't load the new config. `/mcp` should then list gbrain.

**`gbrain doctor`:** it scored 95/100. The one warning says Claude Code has no gbrain registration, but `claude mcp get` shows it registered and connected. I expect the warning to clear once a new session has used it.

**Settings now in effect:**

| Setting | Current | To change |
|---|---|---|
| Search mode | `conservative` (4K token budget, no reranker), the right choice with no keys | `gbrain config set search.mode balanced` or `tokenmax`; both work much better with a key |
| Automatic saving | off: facts are saved only when you ask | `gbrain config set memory.auto_writeback salient` |
| Free upkeep | on while a session is open | `gbrain config set maintenance.auto false` |
| Conversation archive | on: one redacted page per conversation per day; nothing leaves this machine without a key | `gbrain transcripts archive off` |
| Starter pages | none | `gbrain setup claude-code --shape personal` |

I left automatic saving off even though gbrain recommends `salient`. Its docs say that consent has to come from you, so it's your call.

Search mode controls how much text the agent pulls in per query. gbrain's estimate at 10,000 queries a month:

| Mode | Haiku 5.5 | Sonnet 5.5 | Opus 5.5 |
|---|---|---|---|
| conservative | $4 | $80 | $160 |
| balanced | $10 | $200 | $400 |
| tokenmax | $20 | $400 | $800 |

That's input to whatever model you already run; gbrain itself charges nothing. If you'd rather not keep a machine running, gbrain.io offers a hosted version that can import this brain.
