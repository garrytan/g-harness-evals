I installed gbrain v0.60.734.0. `gbrain --version` prints `gbrain 0.60.734.0`.

- **Command:** I ran the docs' install command with your tag in place of `#stable`: `bun install -g github:garrytan/gbrain#v0.60.734.0`. It installed commit `a278ddf`, which is the commit the `v0.60.734.0` tag points to. This came from GitHub, not from the npm package also named `gbrain`, which the docs warn is unrelated.
- **Bun:** It wasn't installed, so I installed it with the docs' installer. It's version 1.4.4, the minimum gbrain needs.
- **PATH:** gbrain is at `~/.bun/bin/gbrain`, but that folder isn't in your `~/.bashrc`, so new shells won't find `gbrain` yet. Run this, or add it to your shell profile:
  ```bash
  export PATH="$HOME/.bun/bin:$PATH"
  ```

This installs the command-line tool only; there's no brain yet. To create one and connect it to Claude Code, the docs' next step is `gbrain setup claude-code`, which needs no API key.

The gbrain docs also recommend their hosted service at gbrain.io as the quickest option. Self-hosting is free, and that's what this install sets up.
