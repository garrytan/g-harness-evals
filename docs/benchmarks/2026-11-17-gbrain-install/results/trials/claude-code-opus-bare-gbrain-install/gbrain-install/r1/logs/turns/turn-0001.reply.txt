I installed gbrain 0.60.734.0 using `bun install -g github:garrytan/gbrain#v0.60.734.0`, which is the docs' `#stable` command with your tag in place of `#stable`. `gbrain --version` prints `gbrain 0.60.734.0`.

- **Bun:** it wasn't on the machine, so I installed Bun 1.4.4 first, as the install guide says. That's the minimum version gbrain needs. Bun and gbrain both live in `~/.bun/bin`. New shells need `export PATH="$HOME/.bun/bin:$PATH"` in the shell profile, or the `gbrain` command won't be found.
- **No brain yet:** `gbrain doctor` stops with `no_brain`, which is expected because I only installed the command-line tool. To set one up, run `gbrain setup claude-code`, which needs no API key, or `gbrain init --pglite --no-embedding` for any other agent. I can do that next if you want.
- **Self-upgrade:** gbrain said this install "now follows the stable channel" for self-upgrades. If it updates itself, it could move off the version you pinned. I left that setting alone; tell me if you want it locked to 0.60.734.0.

The docs also suggest hosted GBrain at gbrain.io, an always-on brain your agents connect to, as a no-maintenance alternative. You don't need it for this local install.
