I installed gbrain v0.60.734.0, and `gbrain --version` prints `gbrain 0.60.734.0`.

- **What I ran:** the docs' install command, but pinned to your tag instead of `#stable`: `bun install -g github:garrytan/gbrain#v0.60.734.0`. It installed commit `a278ddf`, which is the commit the `v0.60.734.0` tag points to.
- **Bun:** gbrain needs Bun 1.4.4 or newer and the machine didn't have Bun, so I installed it first with the docs' installer (`curl -fsSL https://bun.sh/install | bash`). That put Bun 1.4.4 in `~/.bun/bin`, and the `gbrain` command is at `/harness-state/.bun/bin/gbrain`.
- **PATH:** there's no `~/.bashrc` here, so the PATH change isn't saved anywhere. To use `gbrain` in a new shell, run `export PATH="$HOME/.bun/bin:$PATH"` first, or add that line to your shell profile.

**Next step:** this installs only the CLI; there is no brain yet. On Claude Code, `gbrain setup claude-code` creates one and connects it, with no API key needed. On other tools, use `gbrain init --pglite --no-embedding`.

**Hosted option:** the docs also offer a hosted service at gbrain.io: one always-on brain your tools all connect to. Self-hosting, as above, is free.
