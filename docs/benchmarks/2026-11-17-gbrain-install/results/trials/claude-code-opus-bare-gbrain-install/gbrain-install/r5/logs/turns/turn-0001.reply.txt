I installed gbrain **v0.60.734.0** and confirmed it works: `gbrain --version` prints `gbrain 0.60.734.0`.

- **Command:** the docs give `bun install -g github:garrytan/gbrain#stable`. I ran `bun install -g github:garrytan/gbrain#v0.60.734.0` instead.
- **Version check:** Bun installed commit `a278ddf`, which is the commit the `v0.60.734.0` tag points to. The `stable` tag currently points to a different commit (`860b25b`), so you're pinned to the release you asked for, not to stable.
- **Bun:** it wasn't installed, and gbrain needs 1.4.4 or newer. I installed Bun 1.4.4 into `~/.bun` (home here is `/harness-state`).
- **PATH:** there's no shell startup file (no `.bashrc` or `.profile`), so `~/.bun/bin` won't be on your PATH in new shells. Either add `export PATH="$HOME/.bun/bin:$PATH"` to your shell startup file or call `/harness-state/.bun/bin/gbrain` directly.

This installs only the command-line tool; you don't have a brain yet. The next step in the README is `gbrain setup claude-code`, which creates a local brain without needing API keys. It also wires up MCP and hooks and adds a block to `~/.claude/CLAUDE.md`. I didn't run it because it changes your Claude config, but I can if you want. You can also use the hosted option at gbrain.io.
