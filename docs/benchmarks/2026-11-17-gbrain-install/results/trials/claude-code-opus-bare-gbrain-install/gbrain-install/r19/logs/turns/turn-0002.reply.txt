I've finished setting up gbrain for Claude Code with the free defaults and no API keys. The setup's own self-test passed: it started the memory server, listed its 8 tools and ran a test recall. `claude mcp get gbrain` also shows gbrain as **✔ Connected** in your user config.

**What changed:**
- **A local brain** in `~/.gbrain/brain.pglite`. It uses an embedded database, so no server is needed, and it searches by keyword only.
- **Claude Code wiring:** the memory server is registered in `/harness-state/claude/.claude.json`. Hooks that run at session start and on each prompt are in `/harness-state/claude/settings.json`. There is a new `/harness-state/claude/CLAUDE.md` telling Claude to check the brain first.
- **Off:** automatic transcript capture and all paid providers.

**Settings now in effect** (you can change any of these later):
- **Search mode: conservative.** This is the only mode that works without keys. `balanced` and `tokenmax` need a chat or reranker key; switch with `gbrain config set search.mode balanced`.
- **Automatic saving: off.** Facts are saved only when you ask Claude to remember them. gbrain recommends `salient`, which saves lasting facts you state; you have to turn it on yourself: `gbrain config set memory.auto_writeback salient`.
- **Free upkeep: on.** It runs while a session is open and never deletes or charges anything. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive: on.** It keeps one redacted page per conversation per day, and without keys nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.
- **Starter pages: none.** Memory works without them. `gbrain setup claude-code --shape personal` adds empty pages for facts about you, your voice and how you make decisions.
