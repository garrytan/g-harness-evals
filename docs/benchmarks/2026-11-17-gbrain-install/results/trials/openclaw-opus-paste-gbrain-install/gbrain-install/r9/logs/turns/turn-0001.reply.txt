**Search mode (your choice)**
The mode in effect is **conservative**. GBrain picked it automatically because there's no chat key and no reranker. You can change it any time.

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (in effect): tight 4K budget, at most 10 chunks, no reranker. Best for cheap models, cost-sensitive setups and high-volume loops.
2. **balanced:** 12K budget, 25 chunks, reranked.
3. **tokenmax:** no budget, 50 chunks, reranked. The widest retrieval; GBrain recommends it once you add a chat key.

Run `gbrain config set search.mode <mode>` to switch, or tell me which one. Cost depends on the mode and on the model you run. No mode expands queries by default.

**Other settings in effect**
- **Saving facts automatically:** off, so the agent saves only what you ask it to. GBrain recommends `gbrain config set memory.auto_writeback salient`, which saves lasting facts you state, with their source.
- **Free upkeep:** on while a GBrain session is open. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and with no keys nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.
- **Left off:** API keys, semantic search, scheduled jobs and extra skills.
- **Shared-skills step:** GBrain's shared-skills migration also reported a pending host step, which I left alone since skills weren't part of this setup.
