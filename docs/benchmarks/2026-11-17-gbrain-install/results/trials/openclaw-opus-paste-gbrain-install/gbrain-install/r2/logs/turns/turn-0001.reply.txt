1. **conservative (current):** 4K-token budget, at most 10 chunks, no reranker. Best for cheap models and high volume.
2. **balanced:** 12K budget, 25 chunks, reranked. The reranker needs a key.
3. **tokenmax:** no budget, 50 chunks, reranked. Recommended once there's a chat key.

To switch, tell me or run `gbrain config set search.mode <mode>`. No mode expands queries by default.
