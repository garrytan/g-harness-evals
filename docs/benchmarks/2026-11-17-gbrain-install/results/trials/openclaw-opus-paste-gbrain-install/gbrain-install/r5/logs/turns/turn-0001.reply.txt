**Search mode: conservative is in effect, and you can change it any time**
It was picked automatically because there's no chat API key and no reranker. Here is GBrain's cost matrix, as printed:
```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
1. **conservative** (in effect): about 4K tokens per lookup, at most 10 results, no reranking. Suits cheap models and high volume.
2. **balanced:** about 12K tokens, 25 results, reranked.
3. **tokenmax:** no budget cap, 50 results, reranked. This is GBrain's recommendation once you add a chat key. The widest retrieval.

Cost depends on both the mode and the model you run. This agent runs Opus 5.5, so that's the column that applies. The prices are GBrain's published examples, not what your subscription charges. Query expansion is off in every mode. Switch modes with `gbrain config set search.mode <mode>`; balanced and tokenmax only rerank once a reranker key is configured.
