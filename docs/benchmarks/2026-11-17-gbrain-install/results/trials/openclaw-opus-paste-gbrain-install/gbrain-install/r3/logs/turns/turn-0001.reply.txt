**Search mode: `conservative` is in effect.** gbrain picked it because there's no chat model key and no reranker. You can change it any time; nothing is waiting on an answer:

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative:** 4K token budget, at most 10 chunks, no reranker. Suits cheap models and high volume.
2. **balanced:** 12K budget, 25 chunks, reranked.
3. **tokenmax:** no budget, 50 chunks, reranked. The widest search; recommended once you have a chat key.

Switch with `gbrain config set search.mode <mode>`. These are estimates of what the retrieved text costs your model to read, not prices for your subscription. A keyless brain never expands queries.

**Other settings in effect:**
- **Automatic saving:** off, so I save only what you ask me to remember. gbrain recommends `gbrain config set memory.auto_writeback salient`, which saves durable facts you state, with provenance.
- **Upkeep:** free upkeep runs while a gbrain session is open. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.

Without an embedding key, search matches words, not meaning, so a differently worded question can miss a saved fact. Turning on semantic search needs a key and your go-ahead.

There is also hosted GBrain at gbrain.io if you'd rather have one always-on brain shared across apps. It's optional and paid, and the local install above doesn't depend on it.
