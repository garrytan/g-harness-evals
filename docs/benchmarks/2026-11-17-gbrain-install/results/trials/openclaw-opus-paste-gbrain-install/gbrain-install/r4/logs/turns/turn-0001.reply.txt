**Search mode: conservative is on now.** GBrain picked it automatically because there's no chat or reranker key. You can switch at any time:

```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```

1. **conservative** (on now): up to 4K tokens and 10 chunks per lookup, no reranking. Best for cost-sensitive or high-volume use.
2. **balanced:** up to 12K tokens and 25 chunks, reranked.
3. **tokenmax:** no token limit, 50 chunks, reranked. This retrieves the most.

The costs above are estimates of what the retrieved text adds to your model's input, not GBrain prices. Reranking in balanced and tokenmax only runs once a reranker key is set up. To switch, tell me the mode or run `gbrain config set search.mode <mode>`.
