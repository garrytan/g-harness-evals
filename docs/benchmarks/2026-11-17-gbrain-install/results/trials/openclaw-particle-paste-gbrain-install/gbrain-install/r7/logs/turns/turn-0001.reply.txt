1. **conservative** (in effect) — tight 4K budget, 10 chunks max, no reranker. Best for Haiku-class subagents, cost-sensitive or high-volume loops.
2. **balanced** — 12K budget, 25 chunks, reranked. Needs a reranker key (Voyage) to actually rerank.
3. **tokenmax** (recommended once you add a chat key) — no budget, 50 chunks, reranked; widest retrieval.

`gbrain query` doesn't expand by default in any mode (`--expand` forces it, `--no-expand` skips); `gbrain search` and the memory verbs never expand. Say the word and I'll run `gbrain config set search.mode <mode>` — with tokenmax and the old shape also `gbrain config set search.searchLimit 20`.
