### Search mode

**Conservative is active** because there’s no chat key or reranker configured. You can switch at any time:

- **Conservative:** 4K-token budget, up to 10 chunks, no reranker. Recommended for this keyless setup.
- **Balanced:** 12K-token budget, up to 25 chunks; uses a reranker if configured.
- **Tokenmax:** No token cap, up to 50 chunks; uses a reranker if configured.
