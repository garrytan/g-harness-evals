### Search mode: `conservative` is active

| Mode | Retrieval behavior |
|---|---|
| **Conservative** | 4K-token budget, up to 10 chunks, no reranker. Recommended for this keyless setup. |
| **Balanced** | 12K-token budget, up to 25 chunks; reranks if a provider is configured. |
| **Tokenmax** | No token-budget cap, up to 50 chunks; reranks if a provider is configured. |

These are guide estimates, not your OpenClaw subscription prices. You can switch modes anytime without adding a key; search stays keyword-only until you configure a provider.
