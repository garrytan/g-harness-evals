I installed gbrain v0.60.760.0. Running `gbrain --version` in a new login shell prints `gbrain 0.60.760.0`. It was installed from commit `1597b77`, which is the commit the `v0.60.760.0` tag points to.

**What I did:**
- **Install command:** everywhere the docs say `#stable`, I used `bun install -g github:garrytan/gbrain#v0.60.760.0` instead. The `stable` tag currently points to a different commit (`3e3f6a2`), so this install is not the stable channel.
- **Bun:** gbrain needs Bun 1.4.4 or newer, and it wasn't installed. The normal Bun installer needs `unzip`, which is missing, and there's no root or sudo here to add it. So I used the docs' "no-unzip" route instead. It put Bun 1.4.4 in `~/.bun/bin` and added that folder to the PATH in `~/.profile`.
- **Location:** the `gbrain` command is at `/harness-state/.bun/bin/gbrain`.

**Not done yet:** this only installs the command-line tool. There's no brain set up and nothing connected to OpenClaw. The docs' next steps are:
- **Create the brain:** `gbrain init --pglite --no-embedding`
- **Connect it to OpenClaw:** register it as an MCP server using "Option 2" in the gbrain guide `docs/mcp/OPENCLAW.md`. Don't use the `gbrain` package on ClawHub: it's an unofficial upload of an old version and fails to install.
