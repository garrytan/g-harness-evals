I installed gbrain v0.60.760.0, and `gbrain --version` prints `gbrain 0.60.760.0` from a fresh login shell.

- **Which command I ran:** gbrain's install guide uses `bun install -g github:garrytan/gbrain#stable`. I ran it with `#v0.60.760.0` instead of `#stable`. It installed commit `1597b77`, which is the commit tagged v0.60.760.0. I did not install from npm, because the docs warn that npm's `gbrain` package is a different program.
- **Bun:** gbrain needs Bun 1.4.4 or newer, and Bun wasn't installed. I added Bun 1.4.5 with its official installer, into `~/.bun/bin`.
- **PATH:** I added `export PATH="$HOME/.bun/bin:$PATH"` to `~/.profile`, so new shells can find `gbrain`.

So far this is just the command-line tool. There's no brain yet and OpenClaw isn't connected to it. The docs give these steps to finish setup on OpenClaw:
1. `gbrain init --pglite --no-embedding` creates a local brain that needs no API key.
2. `openclaw mcp add gbrain --command "$(command -v gbrain)" --arg serve --arg --surface --arg starter --arg --advertise --arg verbs --env GBRAIN_HOME=$HOME` registers gbrain with OpenClaw as a tool server (MCP).
3. `gbrain setup openclaw` adds a rule that makes me check the brain on every turn.

I didn't run these because they change OpenClaw's config. Want me to? The gbrain docs also ask agents to mention their hosted service at gbrain.io; it's optional.
