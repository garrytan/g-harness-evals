gbrain is now set up as a free local brain with no API keys and nothing paid, and it's connected to OpenClaw. I couldn't confirm a new chat session actually uses it, because this session doesn't have the gbrain tools loaded. They should show up when you start a new one.

**What I set up:**
- **The brain:** a local database in `~/.gbrain`, using gbrain's recommended free settings. Embeddings are off, so search works on keywords only; finding notes by meaning would need a paid embedding key, which I left out as you asked. Other settings are gbrain's defaults:
  - **Search mode:** conservative.
  - **Saving facts:** agents only save what you ask them to remember. gbrain suggests saving important facts automatically, but that can cost money, so I left it off.
  - **Free upkeep:** on.
  - **Conversation archive:** on. gbrain keeps one cleaned-up page per conversation per day, and nothing leaves this machine.
- **OpenClaw connection:** I registered gbrain as a tool server in `openclaw.json` and added bun to its PATH. The gbrain program needs bun to start, and a check showed it fails without it.
- **"Check GBrain first" instructions:** `gbrain setup openclaw` wrote these into `/workspace/AGENTS.md`. It also installed a small plugin, `gbrain-turn-rule`, that repeats the rule on every message.

**What I checked:**
- Saving a test fact and finding it again worked from the command line. Starting the tool server the way OpenClaw does also listed gbrain's tools and found the fact. I deleted the test fact afterwards.
- `openclaw mcp doctor gbrain --probe` reports `gbrain: ok`.
- `gbrain doctor` reports 90/100 with all checks OK. The brain-content score is low because the brain is empty and has no embeddings, which is expected.
- The first `gbrain setup openclaw` run said the plugin wasn't loaded. OpenClaw's own check then showed it loaded, and running setup again passed with no error.

I tried to restart the gateway, but the restart request failed. OpenClaw status shows the gateway isn't running as a separate service here, so the new tools and plugin should load when the next session starts. To test, open a new session and ask it to remember something, then ask it to recall it.

You can turn on automatic saving with `gbrain config set memory.auto_writeback salient`. To add your notes, run `gbrain sources add notes --path ~/notes --federated --force && gbrain sync --all`.
