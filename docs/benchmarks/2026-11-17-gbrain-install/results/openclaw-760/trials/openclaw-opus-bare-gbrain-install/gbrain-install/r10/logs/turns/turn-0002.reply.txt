3. **"Check gbrain first" rule:** `gbrain setup openclaw` wrote two things:

**Settings I left at gbrain's defaults**
- **Saving facts:** agents only save what you ask them to remember. `gbrain config set memory.auto_writeback salient` turns on saving important facts you state.
- **Upkeep:** free background upkeep is on and never deletes or pays for anything.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and without an API key nothing leaves this machine. `gbrain transcripts archive off` turns it off.
