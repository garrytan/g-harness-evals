**Worth knowing:**
- **Newer than stable:** v0.60.760.0 is newer than the version the `stable` tag currently points to (`stable-v0.60.753.0`). On first run, gbrain said this install follows the stable channel for self-upgrades. To get every release instead, run `gbrain config set self_upgrade.channel alpha`.
- **No brain yet:** `gbrain doctor` reports `no_brain`. If you want a local brain, run `gbrain init --pglite --no-embedding` (no API key needed), or `gbrain setup <harness>` to connect it to an agent. I didn't do either, since you only asked for the install.
