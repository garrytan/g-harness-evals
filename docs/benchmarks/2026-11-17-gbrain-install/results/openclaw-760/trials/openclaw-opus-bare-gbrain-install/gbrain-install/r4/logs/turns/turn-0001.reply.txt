I installed gbrain **0.60.760.0**. The docs' install command is `bun install -g github:garrytan/gbrain#stable`, so I ran it with your tag in place of `#stable`: `bun install -g github:garrytan/gbrain#v0.60.760.0`.

- **What's installed:** `gbrain --version` reports `gbrain 0.60.760.0`, built from commit `1597b77`, which is the v0.60.760.0 release.
- **Bun:** it wasn't on this machine, so I installed Bun 1.4.5 first using the installer the docs give (they need 1.4.4 or newer).
- **Location:** the program is at `/harness-state/.bun/bin/gbrain`. The Bun installer didn't add that folder to the command search path in any shell startup file, so a new terminal won't find `gbrain` by name. Use the full path, or run `export PATH=$HOME/.bun/bin:$PATH`. I can add that line to `~/.bashrc` if you want.
- **Not a stable-channel release:** v0.60.760.0 is a newer release that hasn't been promoted to stable. The stable tag currently points to v0.60.753.0. On first run, gbrain said this install "now follows the stable channel," but the docs say updates are never installed without your say-so unless you turn on automatic upgrades.
- **No brain yet:** `gbrain doctor` stops with `no_brain`, which is expected on a fresh install. The fix it suggests is `gbrain init --pglite --no-embedding`, and I haven't run it. I can set up a local brain next if you want one.
