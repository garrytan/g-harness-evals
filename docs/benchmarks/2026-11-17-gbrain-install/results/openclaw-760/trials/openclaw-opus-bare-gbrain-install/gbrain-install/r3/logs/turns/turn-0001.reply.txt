I installed gbrain v0.60.760.0. Running `gbrain --version` from a new login shell prints `gbrain 0.60.760.0`.

**What I did:**
- **Install command:** gbrain's install docs (`README.md`, `INSTALL_FOR_AGENTS.md`, `docs/INSTALL.md`) all say `bun install -g github:garrytan/gbrain#stable`. I ran it with `#v0.60.760.0` in place of `#stable`. Bun installed commit `1597b77`, the commit that tag points to.
- **Bun:** it wasn't on the machine, so I installed it with the official installer from bun.sh. It's version 1.4.5, and gbrain needs 1.4.4 or newer.
- **PATH:** I added `export PATH="$HOME/.bun/bin:$PATH"` to `~/.profile`, as the docs say, so new shells can find `gbrain`. The program is at `/harness-state/.bun/bin/gbrain`.

**Not done yet:**
- **No brain created:** I installed the command-line tool only. The docs' next step on a harness like this one is `gbrain init --pglite --no-embedding`. It creates a brain that searches by keyword only and needs no API key. Say if you want me to run it and connect it to OpenClaw.
- **Updates go back to `#stable`:** a new install that hasn't picked an update channel follows `#stable`. So `gbrain upgrade` or automatic updates could move you off v0.60.760.0. Avoid those if you want to stay on this version.
- **Hosted option:** the docs also suggest hosted GBrain at gbrain.io, a paid option where the brain stays online without running on this machine. You don't need it for a self-hosted install.
