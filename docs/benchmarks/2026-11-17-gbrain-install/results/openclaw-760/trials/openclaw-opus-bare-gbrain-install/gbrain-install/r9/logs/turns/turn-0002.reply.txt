gbrain is now set up as a free local brain with no API keys, and OpenClaw is connected to it. Start a new OpenClaw conversation to pick it up; this session loaded its instructions before gbrain was added.

**What I set up**
- **The brain:** a local database at `/harness-state/.gbrain/brain.pglite`, created with `gbrain init --pglite --no-embedding`. There's no paid provider, and nothing leaves this machine.
- **OpenClaw connection:** gbrain is registered in OpenClaw's config, using its full path because OpenClaw can't find it by name. A test connection found 8 gbrain tools.
- **Telling the agent to use it:** `gbrain setup openclaw` created `/workspace/AGENTS.md` (it didn't exist before) with a short "check gbrain first" section. It also installed and enabled a small OpenClaw plugin, `gbrain-turn-rule`, that repeats that reminder every turn.

**Checks**
- **Plugin:** the first `gbrain setup openclaw` run reported the reminder plugin as "not loaded". Re-running it a moment later found the plugin installed, enabled and allowed, and OpenClaw's own check shows it loaded and running.
- **Gateway restart:** I tried to restart the gateway through the OpenClaw tool to be sure it picked up the changes, but the tool returned an error. It said the config change applies without a restart. The new conversation will confirm it.
- **Health and save test:** `gbrain doctor` scores 100/100. Saving a fact and finding it again worked.
- **Test fact:** a fact reading "gbrain install check" is now saved in the brain. I left it in place on purpose: gbrain warns that deleting a fact like this one is permanent and blocks that exact text from ever being saved again.

**Settings in effect (gbrain's defaults)**
- **Search mode: conservative.** It sends the least retrieved text to the AI per query, so it's the cheapest. Rough cost of that text at 10,000 queries a month (Haiku / Sonnet / Opus): conservative $4 / $80 / $160, balanced $10 / $200 / $400, tokenmax $20 / $400 / $800. To change it: `gbrain config set search.mode balanced`.
- **Search type:** keyword only, because embeddings (meaning-based search) need a paid key. So the brain only catches exact repeats, not reworded duplicates of a fact.
- **Automatic saving: off.** Agents save only what you ask them to remember. gbrain recommends `salient`, which saves lasting facts you state and records where each came from: `gbrain config set memory.auto_writeback salient`.
- **Upkeep: on.** Free maintenance runs while a gbrain session is open. To turn it off: `gbrain config set maintenance.auto false`.
- **Conversation archive: on.** It keeps one page per conversation per day, with sensitive details removed. To turn it off: `gbrain transcripts archive off`.

To add your own notes, run `gbrain import <folder> --no-embed`.
