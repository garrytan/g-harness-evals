**Search mode (you can change it any time)**
gbrain picked `conservative` because there's no chat key and no reranker. This setting controls how much retrieved text goes into each answer:
```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
1. **conservative** (in effect): 4K-token budget, at most 10 chunks, no reranker. Best for cost-sensitive or high-volume use.
2. **balanced:** 12K budget, 25 chunks, reranked.
3. **tokenmax:** no budget, 50 chunks, reranked. The widest retrieval, recommended once a chat key is added.

Without a key there is no reranker, so balanced and tokenmax just return more chunks. To switch, run `gbrain config set search.mode <mode>`, then check with `gbrain search modes`. Your model's cost depends on both the mode and the model you run; these are estimates, not your actual subscription prices.
