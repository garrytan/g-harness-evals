**Search mode: conservative is in effect.** gbrain picked it because there's no chat key and no reranker. You can change it any time; nothing is waiting on your answer.
```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
1. **conservative** (in effect): 4K token budget, at most 10 chunks, no reranker. Best for cheap subagents and high-volume use.
2. **balanced**: 12K budget, 25 chunks, reranked.
3. **tokenmax**: no budget, 50 chunks, reranked. This is gbrain's pick once a chat key is set.

These are estimates of what your model pays to read retrieved text, not prices for your subscription. Balanced and tokenmax only rerank with a reranker key, which this keyless setup doesn't have. To switch, run `gbrain config set search.mode <mode>` and check with `gbrain search modes`.

**Other settings in effect**
- **Saving facts:** I only save what you ask me to remember. gbrain recommends `gbrain config set memory.auto_writeback salient`, which saves durable facts you state, with their source.
- **Upkeep:** free upkeep runs while my gbrain session is open. Turn it off with `gbrain config set maintenance.auto false`.
- **Conversation archive:** on. It keeps one redacted page per conversation per day, and nothing leaves this machine. Turn it off with `gbrain transcripts archive off`.

The docs also offer a hosted version at gbrain.io as an alternative: one always-on brain that several agent apps can connect to. Everything here runs locally and is free.
