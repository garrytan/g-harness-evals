**Search mode: conservative is in effect.** GBrain picked it because there's no chat key and no reranker. You can change it at any time:
```
Estimated downstream input cost of the retrieved payload @ 10K queries/mo:

                  Haiku 5.5     Sonnet 5.5    Opus 5.5
                  ($0.10/M in)  ($2/M in)     ($4/M in)
  conservative    $4/mo         $80/mo        $160/mo
  balanced        $10/mo        $200/mo       $400/mo
  tokenmax        $20/mo        $400/mo       $800/mo

  Assumed payload per query: conservative 4K, balanced 10K, tokenmax 20K tokens.
  Scales linearly: x10 for 100K queries/mo, /10 for 1K. 200x corner-to-corner spread.
  Embedding, reranking and query expansion are separate provider charges.
```
1. **conservative:** 4K budget, at most 10 chunks, no reranker. Best for Haiku-class models and cost-sensitive or high-volume use.
2. **balanced:** 12K budget, 25 chunks, reranked.
3. **tokenmax:** no budget, 50 chunks, reranked. The widest retrieval; GBrain recommends it once a chat key is set.

To switch, run `gbrain config set search.mode <mode>` (or just tell me), and check with `gbrain search modes`. Queries are never expanded by default in any mode. Without keys, balanced and tokenmax mostly mean bigger payloads, because the reranker can't run.

**Other settings in effect**
