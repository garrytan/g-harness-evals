1. **conservative** (in effect): 4K budget, 10 chunks max, no reranker. Best for Haiku, cost-sensitive setups and high-volume loops.
2. **balanced**: 12K budget, 25 chunks, reranked.
3. **tokenmax**: no budget, 50 chunks, reranked; the widest retrieval, recommended once you add a chat key.

To switch, run `gbrain config set search.mode <mode>`, then `gbrain search modes` to confirm. Without keys, search matches exact words only.
