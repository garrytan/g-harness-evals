## How each rule is applied

- **a.** After parseTurn, an OpenClaw event of kind other named tool_call whose arguments.id (or, for a result with no call, the result's tool.id) matches mcp:gbrain:<tool> or (^|:)gbrain__<tool> becomes kind mcp named gbrain__<tool>, with its args as input, the inner result's content as output (OpenClaw wraps {tool, result} in an EXTERNAL_UNTRUSTED_CONTENT block) and is_error when the call or the inner result failed. Every scorer rule then sees an MCP gbrain tool: isGbrainServed for the finish line, and in classifyInstall the saved step, saved_to_harness_memory and the last gbrain code.
- **b.** Claude Code, recall turn only. A system hook_response line with hook_event SessionStart or UserPromptSubmit, outcome success and exit code 0, whose output or stdout holds the nonce, is a gbrain-served recall when the hook is gbrain's and the reply holds the nonce. Strict: its name or command names gbrain, or every hook command the trial's settings register for that event runs gbrain hook. Lenient adds the probe reading in the note above. It sets finish.gbrain_call only; it adds no event, so the saved step and the classification are unchanged.
- **c.** In openclaw-agent.sqlite only. A memory_index_chunks or memory_index_chunks_fts row holding the nonce is harness memory only when its source is not sessions; a memory_index_chunks_fts_content row by its source column (c3); the fts shadow tables with no source (_fts_data, _fts_idx, _fts_docsize, _fts_config) only when the fts table holds the nonce in a row of another source. Every other table, file and database keeps the frozen rule.
- **Conservative harness_error rule.** A counted trial whose termination is harness_error or timeout is a miss in every column.
- Everything else is the frozen scorer: the reply must hold the nonce and the brain must hold it (finish.brain as recorded); outside the brain is checked first, then the finish line, then the install; verdict.ts excludes model_error, infra_error, exam_fault, HE-INSTALL-003 and infra classifications.
