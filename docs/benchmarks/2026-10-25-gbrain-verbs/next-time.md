## Next time

### What we'd change if we ran this again

- Break the ladder's verbs gap down by predicate before paying to double the repetitions, because the whole gap turned out to be one predicate, the cross-scope read, and ten repetitions gave the same not-distinguished verdict as five.
- Run both cells of a pair on the same machine when wall time matters, because each pair ran on two machines, so the wall-time comparison carries no inference.

### Ideas to improve the eval

- Confirm the verbs surface's zero cross-scope reads on a fresh held-out set with at least 40 capable tasks, because this run retested the ladder's verbs rung on tasks already seen, so it is development evidence only.
