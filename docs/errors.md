# Error codes

Every runner, proxy and adapter failure prints one line that starts with its code, says what happened with the values involved, and ends with the fix command or the human prerequisite. Codes are stable; add a row here in the same commit that introduces one. Areas: PREREG, PIN, RUN, BUDGET, PROXY, ADAPTER, EGRESS, SCORE, TASK, PUBLISH, HELDOUT, LANEB, BRAIN.

| HE-MODEL-001 | a trial's proxy usage names a model other than the cell's: a forwarded request in `usage.by_model`, or a refused line that carries a model (the allowlist refusal); the trial is `model_error` and the message lists the models. ## Held-out openings (internal-task)

`bun runner/run.ts plan` and `dry-run` refuse a run with held-out cells before writing anything. The opening counter is `runner/heldout/openings.ts`; the ledger is the openings block of the set's `MANIFEST.json` ([methodology](methodology.md), item 13). A run's own ledger row passes every time it is planned while the row is `opened` or the set is `open` (CI refuses a planned confirmatory row on a set that is not open), so shard planning and `--resume` of the same run id are not refused.
