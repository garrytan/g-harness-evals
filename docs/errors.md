# Error codes

Every runner, proxy and adapter failure prints one line that starts with its code, says what happened with the values involved, and ends with the fix command or the human prerequisite. Codes are stable; add a row here in the same commit that introduces one. Areas: PREREG, PIN, RUN, BUDGET, PROXY, ADAPTER, EGRESS, SCORE, TASK, PUBLISH.

## From internal-task (QM inner-harness cell and probes)

| Code | What | Fix / recovery | Where |
|---|---|---|---|
| HE-MODEL-001 | a trial's proxy usage names a model other than the cell's: a forwarded request in `usage.by_model`, or a refused line that carries a model (the allowlist refusal); the trial is `model_error` and the message lists the models. Refused lines with no model (a route the proxy does not admit) are counted in `usage.refused` and never fail a trial. QM's auxiliary requests are `claude-haiku-5-5`, so on a Haiku cell they are the cell's model; a non-Haiku QM or OpenClaw cell preregisters the allowance as the cell's `utility_models` (provider:model ids), which this check treats as the cell's own while the proxy forwards and prices them when the run's allowlist admits them (internal-task, amendment 2 to `v02-heldout-2026-10`) | check the harness's model mapping (QM's `claude` harness falls back to its default model in silence when `CLAUDE_MODEL` is unsupported, `src/harness/claude-harness.ts` at the pin) or fix the cell | runner/trial/trial.ts |
