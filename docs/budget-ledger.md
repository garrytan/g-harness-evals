# Budget ledger

harness-evals v0.0.12. This page is the program's spend ledger: one row per lane of paid work, in the order the lanes reported, rendered from [docs/ledger/lane-spend.jsonl](ledger/lane-spend.jsonl) (a verbatim copy of the program's drive ledger notes, `harness-eval/ledger/lane-spend.jsonl` in the project drive). Every dollar here is the metering proxy's list-price meter, reserved before each request left and settled to the provider's usage in a SQLite lease ledger (`runner/ledger/budget-ledger.ts`); "committed" is settled spend plus any reservation a machine restart left open, so a lane can only overstate what it spent. The provider-side check, the proxy's priced usage against the provider's own usage report for the key, has never been performed: it needs an Admin API key no run has had, and until then every run's `spend-reconciliation.json` says so ([docs/methodology.md](methodology.md), item 3 as amended on 2026-10-24; [README.md](../README.md), "Known limits"). The ledger files a row names are hashed per run in [docs/receipts-manifest.json](receipts-manifest.json), with the committed spend read back from each file.

Regenerate this page with `bun scripts/budget-ledger.ts` after appending a line to `docs/ledger/lane-spend.jsonl`; `bun scripts/budget-ledger.ts --check` exits non-zero when the page and the JSONL disagree. The render is byte-stable and carries no timestamp.
