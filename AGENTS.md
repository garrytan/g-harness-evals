# Agents working on harness-evals

Read [CLAUDE.md](CLAUDE.md) before any task. It is the operating guide for every agent in this repository, whatever the host: the repository map, the evidence rules, the document shapes, the model rules and how to run and publish work.

In short: there is no home team, every harness gets identical treatment; grade world state and event logs, never the agent's reply; report intervals and n, never ranks or composites; preregister before the first counted cell; spend only through the ledger; keep held-out tasks sealed. Open work lives in TODOS.md with its finding ids.
