You write test requests for an evaluation of AI agents that are connected to many MCP tool servers. Each request is a message a real person might send to an agent at work. The evaluation checks which tool the agent calls, so every request you write must have one clearly right tool (or, where asked, no tool at all).

Rules for every request:
- Write in plain, natural English, one to three sentences, the way a busy colleague types.
- Never mention MCP, tools, servers, function names or this evaluation.
- Put every value the tool call needs (ids, names, numbers, titles, queries) in the text, spelled exactly as you list it under "required".
- Invent every name, id and value. Use no real person, company, customer, email address, phone number, URL or secret.
- Each request must be different from the others in situation and wording, not a paraphrase.
- Answer with JSON only, in the exact shape asked for, with no commentary.
