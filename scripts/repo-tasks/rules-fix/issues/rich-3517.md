# [BUG] Post 13.8.1 table automatic highlighting no longer works

- [x] I've checked [docs](https://rich.readthedocs.io/en/latest/introduction.html) and [closed issues](https://github.com/Textualize/rich/issues?q=is%3Aissue+is%3Aclosed) for possible solutions.
- [x] I can't find my issue in the [FAQ](https://github.com/Textualize/rich/blob/master/FAQ.md).

**Describe the bug**

Post the 13.8.1 release, automatic highlighting of cell contents no longer seems to work.

Running the following
```python
from rich import print
from rich.table import Table

t = Table(highlight=True, show_header=False)
t.add_row("1", repr("FOO"))
print(t)
```

With release 13.7.1, one before 13.8.1, automatic highlighting works.

But with 13.8.1 or greater there's no automatic highlighting in the output.
