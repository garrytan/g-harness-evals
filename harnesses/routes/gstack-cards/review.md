# Pre-Landing PR Review

Review the branch diff against the base for structural issues tests miss.

- **Read the FULL diff before commenting.** Do not flag issues already addressed in the diff.
- Verify claims or flag them as unknown; "this looks fine" is not evidence.
- **Only flag real problems.** Skip anything that's fine.
- For an approved defect regression, write the test and prove it fails for the original defect before changing product code.
- A diagram or test count is not executed proof.
- Cite `file:line` and suggest fixes.
